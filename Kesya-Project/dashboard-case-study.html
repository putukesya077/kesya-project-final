Project Case Study

Coffee Sales Dashboard

Interactive Business Intelligence Dashboard

Project Overview

The Coffee Sales Dashboard is an interactive business intelligence dashboard developed using Microsoft Excel. This project transforms raw transactional sales data into meaningful business insights through Power Query, PivotTables, PivotCharts, KPI Cards, and interactive slicers.

The dashboard allows users to monitor business performance, identify sales trends, compare branch performance, evaluate product categories, and support strategic decision-making through dynamic visualizations.

Project Objectives

📊

Analyze Sales Performance

Monitor revenue, transactions, products, and business growth through interactive visualization.

📈

Business Insights

Transform raw datasets into valuable information that supports managerial decision-making.

⚡

Automate Data

Utilize Power Query to clean, transform, and automate sales data preparation.

🎯

Improve Excel Skills

Apply PivotTables, KPI Cards, PivotCharts, Conditional Formatting, and Dashboard Design principles.

Development Process

This dashboard was developed through a structured workflow, beginning with raw sales data collection and ending with an interactive business intelligence dashboard that supports informed decision-making.

01

Data Collection

The project began by collecting transactional sales data, including order dates, product names, categories, quantities sold, unit prices, payment methods, and branch information. These datasets served as the primary source for all business analyses.

02

Data Cleaning

Power Query was used to clean the dataset by removing duplicates, correcting inconsistent values, formatting dates, and preparing the data for accurate analysis.

03

Data Modeling

The cleaned data was organized into structured tables and connected with monthly targets. This process ensured that KPIs and visualizations could update dynamically based on user interaction.

04

Dashboard Design

Before creating charts, a dashboard layout was planned to determine the placement of KPI cards, slicers, PivotCharts, and supporting visual elements while maintaining a clean and professional appearance.

05

KPI Development

Key Performance Indicators (KPIs) were created to summarize the company's performance, including Total Revenue, Total Profit, Total Transactions, Average Sales, and Target Achievement.

06

Interactive Visualization

PivotTables, PivotCharts, and slicers were implemented to create interactive visualizations that allow users to explore sales trends, product performance, and branch comparisons in real time.

07

Testing & Refinement

The dashboard was tested using multiple filter combinations to verify that every KPI, PivotChart, and slicer functioned correctly. Minor design improvements were also made to enhance readability and overall user experience.
